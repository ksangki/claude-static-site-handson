2장 · 계정 만들기

가입 화면에서 누를 버튼만 기억해요

  • Claude: claude.ai → "Get started" 또는 "Sign up". 이 책의 모든 실습은 무료 플랜으로 충분해요.
  • GitHub: github.com → "Sign up". 사용자 이름은 나중에 여러분의이름.github.io 주소가 돼요.
  • GitHub Desktop: desktop.github.com → "Download for Windows"(또는 "Download for macOS") → "Sign in to GitHub.com" → "Finish".
  • Vercel: vercel.com → "Sign Up" → "Continue with GitHub" → "Authorize Vercel". 무료 플랜은 Hobby예요.

인증 메일이 안 오면 스팸 폴더를 확인하고, 2~3분 기다린 뒤 "Resend"를 눌러보세요.

2장 · 이 책의 핵심 사이클

내 컴퓨터의 파일이 인터넷 사이트가 되는 원리

여러분이 만들 웹사이트는 파일이에요. index.html이라는 이름의 파일 하나가 웹페이지 하나예요.

1. Claude에게 "이런 페이지 만들어줘" 라고 말하기
2. Claude가 만들어준 코드를 복사하기
3. 내 컴퓨터에 파일(index.html)로 저장하기
4. 브라우저에서 열어서 잘 됐는지 확인하기
5. GitHub에 올려서 인터넷에 공개하기

폴더는 서류함, 파일은 서류함 안의 종이라고 생각하면 돼요.

3장 · 코드를 파일로 저장하기

메모장에서 저장할 때 세 칸만 확인해요

  • 파일 이름: index.html
  • 파일 형식: "모든 파일 (*.*)", 이 부분이 중요해요!
  • 인코딩: "UTF-8", 한글이 깨지지 않아요.
  • 저장한 index.html을 더블클릭하면 브라우저에 내 페이지가 열려요. 주소창의 file:/// 경로는 아직 내 컴퓨터에서만 보인다는 뜻이에요.

파일 이름이 index.html.txt가 돼버렸다면 "파일 형식"을 "텍스트 문서 (*.txt)"로 둔 거예요. 이름에서 .txt를 지우고 "예"를 눌러주세요.

쉽게 말하면잼을 담은 병에 "간장"이라고 라벨을 붙이면 아무도 빵에 바르지 않아요. 확장자가 그 라벨이에요.
