# 따라 하면 완성되는 내 첫 웹사이트

> 비개발자를 위한 Claude AI 실습 가이드

<img src="cover.png" alt="따라 하면 완성되는 내 첫 웹사이트 표지" width="320" />

코딩 경험 없는 비개발자가 Claude AI와 대화하며 포트폴리오 사이트와 이벤트 후기 사이트를 직접 만들고, GitHub Pages와 Vercel에 배포하는 핸즈온 가이드입니다.

- **오프닝 영상**: [60초 모션그래픽](https://ksangki.github.io/claude-static-site-handson/media/opening.mp4) · 웹 버전 첫 화면에도 실려 있다
- **EPUB**: [`따라-하면-완성되는-내-첫-웹사이트-v1.0.4.epub`](따라-하면-완성되는-내-첫-웹사이트-v1.0.4.epub) 다운로드

| | 2장 | 도구 준비: 계정 만들고 시작 준비하기 |
| **프로젝트 A** | 3장 | Claude와 첫 대화: "내 소개 페이지 만들어 줘" |
