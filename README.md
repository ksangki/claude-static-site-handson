# 따라 하면 완성되는 내 첫 웹사이트

> 비개발자를 위한 Claude AI 실습 가이드

코딩 경험 없는 비개발자가 Claude AI와 대화하며 포트폴리오 사이트와 이벤트 후기 사이트를 직접 만들고, GitHub Pages와 Vercel에 배포하는 핸즈온 가이드입니다.

## 읽기

- **웹 버전**: [GitHub Pages에서 읽기](https://ksangki.github.io/claude-static-site-handson/)
- **EPUB**: [`따라-하면-완성되는-내-첫-웹사이트-v1.0.0.epub`](따라-하면-완성되는-내-첫-웹사이트-v1.0.0.epub) 다운로드

## 관통 프로젝트

| 프로젝트 | 결과물 | 배포 플랫폼 |
|---------|--------|----------|
| A. 포트폴리오 사이트 | 나를 소개하는 개인 웹사이트 | GitHub Pages |
